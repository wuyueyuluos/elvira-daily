# 与你的日常 · Elvira's Diary

一款面向手机竖屏的日系美少女生活模拟与恋爱养成游戏。

## 当前版本：v0.2 原型

当前已包含：
- 简洁的视觉小说式主界面
- 艾尔薇拉基础角色档案
- 情境对话选择
- 好感、心情、体力、信任、熟悉度等基础状态
- 简单日程展示与虚拟时间推进
- 共同回忆记录
- 浏览器本地存档 / 读档

## 手机试玩

项目使用纯 HTML / CSS / JavaScript，无需安装依赖。可直接打开 `index.html` 试玩。

## 说明

当前角色图像为临时 CSS 原型占位，正式角色立绘和表情素材会单独制作并统一角色设定。当前存档保存在浏览器本机，清理浏览器数据可能导致存档丢失。
