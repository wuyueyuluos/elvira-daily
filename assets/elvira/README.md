# 艾尔薇拉美术资源规范

本目录用于存放《与你的日常》中艾尔薇拉的正式角色素材。

## 目录规划

```text
assets/
└── elvira/
    ├── reference/       # 设定参考图，仅供制作对照，不直接用于游戏
    ├── sprites/
    │   └── base/        # 正式全身立绘
    ├── expressions/     # 独立表情图
    ├── poses/           # 独立动作图
    └── thumbnails/      # 小尺寸预览图（如有需要）
```

## 文件命名

统一使用小写英文、数字和下划线，避免空格及中文文件名：

- 全身立绘：`elvira_standing.png`
- 表情：`elvira_expr_neutral.png`、`elvira_expr_happy.png`、`elvira_expr_shy.png`、`elvira_expr_sleepy.png`、`elvira_expr_sad.png`、`elvira_expr_angry.png`
- 动作：`elvira_pose_sitting.png`、`elvira_pose_reading.png`、`elvira_pose_tea.png`、`elvira_pose_greeting.png`

## 图片规范

- 游戏角色素材优先使用 PNG，并保留真正的透明通道（RGBA）。
- 不要把棋盘格预览、白色背景或灰色背景误认为透明背景。
- 角色素材应完整保留头发、发饰、裙摆、手脚，不要裁掉轮廓。
- 全身立绘建议使用竖版画布，角色居中，四周留少量透明边距。
- 表情素材应采用一致的头部角度、发型、发饰、服装和裁切范围；只改变面部表情。
- 动作素材应维持相同的角色设定、发色、服装和画风。
- 不要把带有文字、标签、边框或多个角色的设定合集直接放进游戏。

## 制作顺序

1. 完成标准站立立绘的透明背景与边缘清理。
2. 以标准立绘为准，制作六张独立表情素材。
3. 制作坐着、看书、喝茶、打招呼等独立动作素材。
4. 在游戏中接入素材，并测试手机竖屏下的显示比例和切换效果。

参考图是美术制作依据，不代表已经具备可直接使用的游戏素材质量。
